# 📱 Contact List - App

Aplicativo mobile desenvolvido com React Native para gerenciamento de contatos. Permite cadastrar, buscar, visualizar e excluir contatos de maneira simples e rápida.

## 🚀 Tecnologias

- React Native
- TypeScript
- React Navigation
- Axios
- Context API

## 📦 Instalação

Clone o repositório e instale as dependências:

```bash
git clone <repo>
cd contactlasaist-app
yarn
```

## 🏁 Rodando o aplicativo

```bash
npx expo start
```

> Certifique-se de ter o [Expo Go](https://expo.dev/client) instalado em seu celular ou use um emulador Android/iOS.

## ✅ Funcionalidades

- [x] Listar contatos
- [x] Cadastrar novo contato
- [x] Buscar por nome
- [x] Remover contato
- [x] Interface amigável e responsiva
